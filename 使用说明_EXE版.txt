DrumQuill（DrumQuill）· EXE 版使用说明
==========================

【第一次使用：安装向导】
   双击 dist\DrumQuill\DrumQuill.exe（或桌面上的「DrumQuill 扒鼓谱」快捷方式）
   → 会自动弹出「安装向导」，列出所有组件，并写清每项：
       装了能得到什么 / 不装会怎样
   → 顶部三个预设，按需选择即可：
       最小可用 —— 只要扒谱，装必需的三项（约 1.5GB）
       推荐     —— 再加 Demucs 分离模型 + 节拍跟踪模型 Beat This + MuseScore 排版 + ffmpeg
                     （谱面跟着音乐真实速度走、PDF 更专业、音频是 MP3）
       全部     —— 连 GPU 加速环境也一起装
     也可以自己勾选任意组合。
   → 点「开始安装」，下载走国内镜像，可断点续传；
     中途关掉窗口没关系，下次打开会接着装（自动回到进度页）。
   → 装完会显示「现在能做什么」：哪些功能可用、哪些走了降级方案。

【没装全也能用】
   · 只有「必需」三项（运行环境 / 核心依赖包 / 转录引擎）缺了才不能扒谱，
     这时主界面会挡住「开始扒谱」并给「立即安装」按钮。
   · 其余组件缺失只会降级，界面上一行说明：
       Demucs 分离模型 → 直接对整曲转录（精度略低、更慢）
       Beat This 拍点模型 → 按全曲一个固定速度记谱，小节容易和音乐对不上
                            （结果页会明确提示，补装后重跑这首歌即可）
       MuseScore      → PDF 改用内置渲染（能看能打印，排版朴素）
       ffmpeg         → 鼓声音频存成 WAV（体积大，照样能听）
       GPU 加速       → 用 CPU 分离（慢约 3 倍，功能不变）

【之后想补装】
   点左侧栏底部的「设置」→ 顶部「能力与组件」：
     · 每行一个组件，后面有单独的「安装 / 补装 / 重装」按钮
     · 「一键补装缺失项」按一下就把没装的补齐
     · 能力清单会实时告诉你现在能做什么、缺什么走什么降级

【选模式：这次要什么】
   选好文件后，「这次要什么」可选四种：
     完整扒谱 —— 鼓谱 PDF + MusicXML + MIDI + 鼓声 MP3（默认）
     只要谱子 —— 只出 PDF / MusicXML / MIDI，不做音频（更快一点）
     只要音频 —— 只出鼓声 MP3（仍会分离与转录）
     只要鼓声 —— 只跑鼓轨分离，直接给纯鼓轨音频（最快，不做转录）
   还能单独选分离设备：自动 / CPU / GPU。

【扒谱】
   方式一：窗口里拖入音乐文件（MP3/WAV/FLAC/M4A），点「开始扒谱」。
   方式二：把音乐文件拖到根目录「一键扒谱.bat」图标上（不开网页直接跑）。
   处理中可以关掉窗口，任务在后台继续；再打开会恢复进度。
   页面会显示「已用 / 预计还需」，六步进度里每一步都标了实际耗时。

【取产物 / 管理产物】
   完成页（PDF 优先）：
     · 标题下面直接显示【鼓谱预览】——第一页谱面，点图进全屏查看器
       （可翻页 ← →、缩放、用系统阅读器打开、保存 PDF）
     · 主按钮「查看鼓谱 PDF」；旁边「保存 PDF」会弹另存为对话框
     · 再往下才是「鼓声试听」，最后是 MusicXML / MIDI 等附加产物
     · 还有「打开输出目录」按钮
   点「保存」会弹出系统的「另存为」对话框，自己选存哪儿。
   最近产物里每行有：?试听 · 产物… · 删除
     · 点「产物…」展开这首歌的全部文件：成品、中间产物（分离出的 drums.wav 等、各个 MIDI）、源音频；
       每个文件都能 查看/试听/保存/定位（打开所在文件夹）/删除
     · 点「删除」一次清掉这首歌的成品和中间产物（源音频默认保留）

【成品位置】
   output\ 目录：歌曲名_鼓谱.pdf / .musicxml / _鼓谱音频.mp3（或 .wav）
   midis\ 目录：校正后的 MIDI。
   完成页可以直接「打开鼓谱 PDF」、试听鼓声、下载四种产物。

【说明】
   · EXE 只是启动器（端口探测 + pywebview 窗口），真正的扒谱管线仍走同目录
     的 run_pipeline.ps1 与 Python 环境，不改变输出位置。
   · 端口 8756 被占时自动换 8757；日志在 app\launcher.log，
     服务日志在 app\service.log 与 app\service_crash.log。
   · 重建 EXE：仓库根目录执行
     .venv\Scripts\pyinstaller.exe --noconfirm --clean build_spec\DrumQuill.spec
   · ADTOF 权重 CC BY-NC-SA 4.0 非商用，见 docs\third_party_licenses.md。



【分离模型怎么选】
   设置 -> 分离模型：可以下载 / 切换 / 删除。实测结论（你自己的人工参考谱，60 秒素材）：
     默认 HTDemucs  整体 0.931 · 镲片 0.818 · 12.9 秒  —— 最快最稳（推荐）
     HTDemucs-FT    整体 0.934 · 镲片 0.870 · 35.0 秒  —— 想再细一点
     MDX-Extra      整体 0.929 · 镲片 0.909 · 42.8 秒  —— 镲片最准，但慢 3 倍
     HTDemucs-6S    整体 0.925 · 镲片 0.783            —— 实验项，镲片最差
   四个模型的整体差距只有 1% 左右：换模型救不了错谱，镲片（吊镲/叮叮）乱才值得换。
   界面会按你的显存给一行挂"本机推荐"：
     没有显卡 / 4-6GB 显存 -> 默认 HTDemucs；6-12GB -> HTDemucs-FT；12GB+ -> MDX-Extra
   分离产物按模型分目录存放：stems\模型名\歌曲名\drums.wav，产物管理里会标注来源模型。

【换了新版本，打开却像没更新？】
   已经自动处理：程序文件一变，再次双击图标时启动器会重启后台服务
   （app\launcher.log 里会写 running service uses stale code (stamp mismatch) -> restart）。
   想强制重启：任务管理器里结束 pythonw.exe（命令行含 app.py）后重新双击图标。


【想让谱子更准：两个开关】
   设置 -> 常用设置里有两项，默认值已经是实测最优，一般不用动：
     · 转录阈值  底鼓,军鼓,嗵鼓,踩镲,吊镲（留空 = 按当前分离模型自动）
       越小越灵敏（会多打出一些音符），越大越保守。实测调优后底鼓/踩镲更灵敏、嗵鼓更严。
     · 量化吸附容差 0-0.5（默认 0.25，0 = 完全不量化）
       原来的做法是把每个音符硬吸到十六分音符上，实测会让准确度明显下降（演奏本来就不在栅格上）。
       现在只吸偏离 25% 以内的音符，谱面照样整齐。
   实测（同一首歌 150 秒，逐类微平均 F1）：改造前 0.81 -> 现在 0.89（前 60 秒）/ 0.83 -> 0.92（后段）。
   另外：力度不再一律 100，试听能听出强弱。

【已知的上限（不是 bug）】
   ADTOF 只输出 5 类鼓：底鼓、军鼓、嗵鼓、踩镲、吊镲。
   没有叮叮镲(ride)，也不分开/闭踩镲 —— 所以 ride 段落常被记成吊镲或踩镲，这类错误调参数救不了。
